# Portfolio icons

28 original upstream SVGs: 24 technologies and GitHub, LinkedIn, Instagram, WhatsApp.

`icon-manifest.json` maps exact content names to local files, colors, pinned sources, SHA-256 hashes and licence notices. Original fills and vector geometry are unchanged. Use a CSS mask/currentColor for muted default marks and the supplied brand color for hover; some original marks contain dark fills that need adaptation to a dark background. Keep labels outside the SVG.

Devicon uses MIT; its notice is retained. Simple Icons uses CC0; its notice and trademark disclaimer are retained. Keycloak metadata also points to Linux Foundation trademark usage guidance. Brand/trademark rights remain with their owners.

Source repositories: [Devicon](https://github.com/devicons/devicon), [Simple Icons](https://github.com/simple-icons/simple-icons). Redownload pinned files only with `python scripts/prepare-responsive-assets.py --refresh-icons`. Normal preparation is offline. Use `--refresh-icons --icons-only` to update icon assets/manifests without regenerating media derivatives or touching videos, CVs or fonts.
